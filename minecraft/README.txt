========================================
   MINECRAFT 666 - HORROR EDITION
========================================

ВНИМАНИЕ! Этот мод содержит хоррор-контент:
- Пугающие звуки и визуальные эффекты
- Психологический хоррор
- Глитчи и искажения
- Фейковые ошибки системы

Не рекомендуется для людей с эпилепсией или
чувствительных к хоррор-контенту.

========================================
   УСТАНОВКА И ЗАПУСК
========================================

1. Убедитесь, что установлена Java 8 или выше
   Проверить: откройте CMD и введите "java -version"

2. Запустите START.bat для обычного режима
   или START_DEBUG.bat для режима отладки

3. Игра запустится автоматически

========================================
   СИСТЕМНЫЕ ТРЕБОВАНИЯ
========================================

Минимальные:
- Windows 7/8/10/11
- Java 8+
- 2 GB RAM
- OpenGL 2.0
- 500 MB свободного места

Рекомендуемые:
- Windows 10/11
- Java 8+
- 4 GB RAM
- OpenGL 3.0+
- 1 GB свободного места

========================================
   КОМАНДЫ МОДА
========================================

/mst - Показать текущий этап мистики
/next - Запустить следующее событие
/x10 - Ускорить события в 10 раз
/mlvl [1-4] - Установить уровень мистики
/mreset - Сбросить мистическое состояние
/wav - Тестовый звук WAV
/ogg - Тестовый звук OGG
/event <название> - Запустить конкретное событие

Запустите игру 5 раз для разблокировки "END MODE"

========================================
   РЕШЕНИЕ ПРОБЛЕМ
========================================

Игра не запускается:
- Проверьте Java: java -version
- Запустите START_DEBUG.bat
- Проверьте наличие всех файлов

Нет звука:
- Проверьте громкость в настройках игры
- Убедитесь, что файлы в game/resources/newsound/glitches/
- Проверьте формат файлов (должны быть .ogg)

Ошибка "Cannot find main class":
- Проверьте наличие minecraft.jar
- Проверьте наличие всех библиотек в libraries/

Чёрный экран:
- Обновите драйверы видеокарты
- Попробуйте запустить с -Xmx512M

========================================
   ФАЙЛЫ И ПАПКИ
========================================

game/ - Игровая директория (НЕ УДАЛЯТЬ)
  ├── assets/ - Ресурсы игры
  ├── resources/newsound/glitches/ - Хоррор звуки
  ├── saves/ - Сохранения миров
  └── screenshots/ - Скриншоты

libraries/ - Библиотеки Java (НЕ УДАЛЯТЬ)
libraries/natives/ - Native библиотеки (НЕ УДАЛЯТЬ)
minecraft.jar - Главный файл игры (НЕ УДАЛЯТЬ)

locked.dat - Создаётся после финального краша
options.txt - Настройки игры (создаётся автоматически)
