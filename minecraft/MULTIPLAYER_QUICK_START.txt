========================================
  MULTIPLAYER HORROR SYNC - QUICK START
========================================

📦 ЧТО БЫЛО ДОБАВЛЕНО:

1. Packet250HorrorSync.java
   - Сетевой пакет для передачи хоррор-событий
   - ID: 250 (зарегистрирован в Packet.java)

2. HorrorEventReceiver.java
   - Обработчик входящих событий на клиенте
   - Поддерживает 60+ типов событий

3. HorrorSyncServerHandler.java
   - Серверный ретранслятор пакетов
   - Рассылает события всем игрокам

4. MysticManager.java (модифицирован)
   - Добавлены методы broadcastHorrorEvent()
   - Автоматическая отправка при триггере событий

5. NetClientHandler.java (модифицирован)
   - Обработчик handleHorrorSync()
   - Интеграция NetworkManager при подключении

========================================

🚀 КАК ИСПОЛЬЗОВАТЬ:

1. АВТОМАТИЧЕСКАЯ СИНХРОНИЗАЦИЯ:
   Все события автоматически синхронизируются
   при триггере в одиночной игре.

2. РУЧНАЯ ОТПРАВКА:
   MysticManager manager = MysticManager.getInstance(mc);
   manager.broadcastHorrorEvent("screamer", 3, 1.5f);

3. ЦЕЛЕВАЯ ОТПРАВКА:
   manager.broadcastHorrorEvent("tunnel_vision", 2, 1.0f, "PlayerName");

4. СЕРВЕРНАЯ ОТПРАВКА:
   HorrorSyncServerHandler.broadcastServerEvent("gdi_glitch_screen", 4, 2.0f, server);

⚙️ КОМПИЛЯЦИЯ:

1. Откройте RetroMCP
2. Нажмите "Recompile"
3. Нажмите "Reobfuscate"
4. Получите jars/reobfuscated.jar

========================================

🧪 ТЕСТИРОВАНИЕ:

1. Запустите локальный сервер
2. Подключите 2+ клиента
3. На одном клиенте выполните: /event screamer
4. Проверьте, что эффект появился у всех
5. Проверьте логи:
   [MysticManager] Broadcasted event: screamer
   [HorrorSync] Received event: screamer
   [HorrorSync Server] Broadcasted to X players

========================================

📝 ЛОГИРОВАНИЕ:

Все компоненты выводят отладочную информацию:
- [MysticManager] - отправка событий
- [HorrorSync] - получение событий
- [HorrorSync Server] - серверная рассылка

========================================

⚠️ ВАЖНО:

1. DLL эффекты работают только на Windows
2. Требуется error404.dll в natives/
3. Серверная часть требует NetServerHandler
4. Нет rate limiting (можно спамить)
5. Нет валидации событий на сервере
