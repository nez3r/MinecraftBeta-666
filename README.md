# Minecraft Beta 1.6.6
Кастомная Minecraft версия со своими страшилками. (Beta 1.6.6.6)


## Требования

- **Операционная система**: Windows Vista и выше
- **Java**: Java 17 или выше - Adoptium
- **Оперативная память**: минимум 1 ГБ ОЗУ
- **Дисковое пространство**: минимум 500 МБ свободного места


# Игра:

## Запуск

### Клиент
Для запуска клиента используйте .bat файл.

### Сервер (мультиплеер)

Для запуска сервера используйте server.jar или .cmd файл:
```batch
start.cmd
```

### Примечания:
- Советуем играть в оконном режиме, так как версия делает приколы на рабочем столе =)
- Есть пасхалка 404. (Multiplayer и World Seed)


### Если ошибка "Не найден указанный модуль"
- Распакуйте архив полностью.
- Проверьте наличие /natives/error404.dll

### Если не хотите разбираться:
- Большинство эффектов и приколов будет недоступно
- Будет более скучно играть.
## Советую играть с DLL.


# Исходники:

## Структура исходника

```
├── conf/                    # Конфигурационные файлы RetroMCP
│   ├── exceptions.exc       # Исключения для деобфускации
│   ├── mappings.tiny        # Маппинги имен
│   └── version.json         # Информация о версии игры
├── minecraft/               # Клиентская часть
│   ├── src/                 # Декомпилированные исходные коды
│   ├── src_original/        # Оригинальные исходные коды
│   ├── output/              # Выходные файлы компиляции
│   ├── dll/                 # Нативные библиотеки
│   ├── Client.launch        # Конфигурация запуска для Eclipse
│   └── options.cfg          # Настройки клиента
├── minecraft_server/        # Серверная часть
│   ├── src/                 # Декомпилированные исходные коды
│   ├── src_original/        # Оригинальные исходные коды
│   ├── Server.launch        # Конфигурация запуска для Eclipse
│   └── options.cfg          # Настройки сервера
├── recompile.bat            # Скрипт автоматической пересборки
└── options.cfg              # Основные настройки проекта
```

## Установка

1. Убедитесь, что установлена Java 17 или выше:
   ```
   java -version
   ```

2. Скачайте и установите RetroMCP-Java-CLI.jar или RetroMCP-Java-GUI.jar

3. Поместите JAR-файл RetroMCP в корневую директорию проекта

4. При необходимости настройте параметры в файле `options.cfg`:
   - `workingDir` - путь к рабочей директории
   - `runargs` - аргументы запуска JVM (по умолчанию -Xms1024M -Xmx1024M)


## Сборка проекта

### Сборка через .bat файл (CLI RetroMCP)

Запустите скрипт пересборки:
```batch
recompile.bat
```
Важно: рядом с батником должна быть CLI версия RetroMCP.

### Сборка через RetroMCP (Gui)

1. Запустите RetroMCP
2. Откройте проект через меню File -> Open
3. Нажмите кнопку "Build" для компиляции

### Параметры сборки

В файле `options.cfg` доступны следующие опции:
- `side=ANY` - сторона сборки (CLIENT, SERVER, ANY)
- `fullbuild=false` - полная пересборка всех классов
- `stripgenerics=false` - удаление дженериков из исходного кода
- `outputsrc=true` - выводить исходные коды после деобфускации

### Сборка через IDE
Сборка может производится с таких IDE как: Eclipse, IntelJ Idea, Windsurf, VS Code.
Для этого откройте проект в самой IDE. Установите нужные расширения для работы с Java и редактируйте проект.

# Важно: перед сборкой нужно предварительно установить версию Beta 1.6.6 в окружении RetroMCP, а затем дополнительно установить библиотеки JNA и JNA-Platform. После этого, скачиваем исходник из репозитория и заменяем содержимое окружения на скачанный.
- После подготовки, можете изменять проект через RetroMCP CLI/GUI или через поддерживаемый IDE.
